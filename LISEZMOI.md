# Balades à pied : version iPhone (web)

La même appli que la version Android, utilisable dans Safari et installable sur l'écran d'accueil.

## Mettre en ligne (GitHub Pages, gratuit)

1. Sur https://github.com, crée un dépôt **public** nommé `balades-pied-web`.
2. **uploading an existing file** : glisse `index.html` et `apple-touch-icon.png`, puis **Commit changes**.
3. **Settings → Pages** : sous *Branch*, choisis `main` et `/ (root)`, puis **Save**.
4. Après une minute, l'adresse est : `https://narnia1633.github.io/balades-pied-web/`

## Installer sur l'iPhone

1. Ouvre l'adresse dans **Safari**.
2. Touche le bouton **Partager**, puis **Sur l'écran d'accueil**.
3. Lance **Balades à pied** et autorise la localisation.

Les favoris sont gardés dans Safari, séparés de ceux de Boucles Vélo.
Pendant une balade, garde l'écran allumé : iOS met le suivi GPS en pause quand l'écran se verrouille.
