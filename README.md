# 🥾 Balades à pied : version iPhone

La version web de [Balades à pied](https://github.com/narnia1633/balades-pied), qui crée des balades
et des randonnées en boucle autour de toi. Elle marche dans Safari et s'installe sur l'écran d'accueil comme une appli.

**👉 [narnia1633.github.io/balades-pied-web](https://narnia1633.github.io/balades-pied-web/)**

## Mettre en ligne (une seule fois)

1. **Settings → Pages** dans ce dépôt.
2. Sous *Branch*, choisis `main` et `/ (root)`, puis **Save**.
3. Une minute après, l'adresse ci-dessus fonctionne.

## Installer sur l'iPhone

1. Ouvre l'adresse dans **Safari**.
2. Touche le bouton **Partager**, puis **Sur l'écran d'accueil**.
3. Lance **Balades à pied** et autorise la localisation.

## Ce qu'elle fait

- Trois modes : **Balade** (avec une option poussette / sans marches), **Rando** et **Montagne**.
- 3 propositions de boucles ou d'allers-retours, avec les sentiers balisés (GR, PR…) sur la carte.
- Distance, dénivelé et temps de marche façon topo de randonnée.
- Alerte si tu risques de finir après le coucher du soleil.
- Profil d'altitude coloré selon la pente.
- Export et partage en GPX, favoris, import de fichiers GPX.
- Mode balade : distance, allure, kilomètres restants, heure d'arrivée et alerte hors parcours.

Toutes les fonctions sont décrites dans le [dépôt de la version Android](https://github.com/narnia1633/balades-pied).

## Bon à savoir

- Pendant une balade, garde l'écran allumé : iOS met le suivi GPS en pause quand l'écran se verrouille.
- Les favoris sont gardés dans Safari, sur ce téléphone, séparés de ceux de Boucles Vélo.
